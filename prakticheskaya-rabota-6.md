# Практическая работа №6

## Программирование. Анализ результатов измерений

**Выполнила:** Горшкова Надежда Константиновна

**Группа:** ИКТ-2613

## 1. Цель работы

Изучить основы программирования на Python и научиться выполнять статистическую обработку результатов измерений.

## 2. Задачи работы

* Ввести набор экспериментальных измерений.
* Вычислить среднее арифметическое.
* Найти минимальное и максимальное значения.
* Рассчитать размах измерений.
* Вычислить среднеквадратическое отклонение.
* Определить относительную погрешность.
* Выполнить фильтрацию выбросов.

## 3. Исходные данные

Для проверки программы использованы семь измерений:

12.5; 12.8; 12.3; 13.1; 11.9; 12.6; 12.4.

## 4. Результаты анализа

| Количество измерений            |         7 |
| Среднее значение                |    12.514 |
| Минимум                         |    11.900 |
| Максимум                        |    13.100 |
| Размах                          |     1.200 |
| Среднеквадратическое отклонение |     0.366 |

## 5. Вывод

В ходе работы была рассмотрена программа на Python для статистической обработки измерений. Были изучены методы вычисления основных статистических показателей и фильтрации выбросов.
