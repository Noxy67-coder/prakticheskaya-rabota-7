# Практическая работа №6

## Тема: Анализ результатов измерений

**Выполнила:** Горшкова Надежда Константиновна

**Группа:** ИКТ-2613

## Цель работы

Разработать программу на языке Python для анализа результатов измерений и вычисления основных статистических характеристик.

## Задачи

1. Организовать ввод количества измерений.
2. Получить числовые значения.
3. Вычислить среднее арифметическое.
4. Найти минимальное и максимальное значения.
5. Рассчитать размах измерений.
6. Вычислить среднеквадратическое отклонение.
7. Определить относительную погрешность.
8. Выполнить фильтрацию выбросов.

## Описание программы

Программа принимает от 5 до 20 измерений, проверяет корректность ввода и выполняет статистическую обработку полученных данных.

## Результат

В результате работы программы пользователь получает основные статистические показатели и список измерений после фильтрации выбросов.

## Вывод

В ходе практической работы были изучены основы программирования на Python, работа с циклами, условиями и списками. Получены навыки статистической обработки результатов измерений.
